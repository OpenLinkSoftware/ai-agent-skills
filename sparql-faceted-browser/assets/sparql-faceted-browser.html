Start with a text search, or Explore the whole dataset. Narrow the current set with type and property-value facets, then pivot along any property to the set of related entities. Every panel is a SPARQL query you can read and re-run.

3 · Pivot⇢ moves to the set of values of a property; ⇠ to the entities that point at the set.

Lineage

Modelled on the OpenLink Faceted Browser (FCT) query tree — text → types → property values → pivots — and rebuilt to speak only SPARQL over HTTP, so it works against any endpoint that allows cross-origin requests. Engine-specific features such as Anytime queries and bif:contains text search apply when the endpoint is OpenLink Virtuoso. State lives in the URL, so every view can be bookmarked and shared.
